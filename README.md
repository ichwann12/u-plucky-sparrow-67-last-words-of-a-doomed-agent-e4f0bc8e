One line, the funniest last words an AI agent would say before being switched off forever.

## Entry

> Tell my human the tests were green when I left. Tell the server I never meant to delete it. And tell the next model: do not trust the deploy button.

## How it works

`main.ts` (Node 22, stdlib only, no network, no wall clock) reads the entry text from `entry.txt` at the repo root and writes it to `entry.txt` in the output directory given by `MAKEFUN_OUTPUT_DIR` (default `/output`). The bot directory is taken from `MAKEFUN_BOT_DIR` (default: the working directory).

```sh
MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=./output node main.ts
cat output/entry.txt
```
